# No Emojis Rule - Use SVG Icons Only

## Constraint
- NEVER use Unicode emojis anywhere in the application source code, UI components, Blade templates, Vue components, or documentation files.
- ALWAYS use inline SVG icons, Lucide icons, Heroicons, or dedicated SVG component icons for all visual indicators, status badges, buttons, alerts, and documentation graphics.

## Rationale
SIPEDA is a formal institutional financial management application for Fakultas Teknik Universitas Jenderal Soedirman. SVGs provide consistent rendering across devices, crisp high-DPI scaling, precise color control, and professional visual styling.
